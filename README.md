### Задача 1: Имена

**Условие:**  
Создать сущность "Имя", которая описывается тремя параметрами: Фамилия, Личное имя, Отчество. Имя может быть приведено к строковому виду, включающему традиционное представление всех трех параметров.

**Алгоритм решения:**
1. Создаем класс `Name` с тремя строковыми полями для хранения компонентов имени
2. Реализуем несколько конструкторов для разных сценариев создания:
   - Только имя
   - Фамилия и имя
   - Все три компонента
3. В методе `ToString()` последовательно проверяем каждый компонент на наличие данных

### Задача 6: Дроби

**Условие:**  
Создать сущность "Дробь" с числителем и знаменателем, поддерживающую операции сложения, вычитания, умножения и деления.

**Алгоритм решения:**
1. Создаем класс `Fraction` с полями для числителя и знаменателя
2. Реализуем алгоритм Евклида для нахождения наибольшего общего делителя (НОД)
3. Метод `Simplify()` автоматически упрощает дробь после операций:
   - Находим НОД числителя и знаменателя
   - Делим оба на НОД
   - Убеждаемся, что знак только в числителе
4. Реализуем математические операции по правилам:
   - Сложение: (a/b) + (c/d) = (a*d + c*b)/(b*d)
   - Вычитание: (a/b) - (c/d) = (a*d - c*b)/(b*d)
   - Умножение: (a/b) * (c/d) = (a*c)/(b*d)
   - Деление: (a/b) / (c/d) = (a*d)/(b*c)

**Тестирование:**

| Входные данные | Ожидаемый результат | Фактический результат |
|----------------|---------------------|------------------------|
| 1/3 + 2/3 | 1 | 1 ✅ |
| 1/3 - 2/3 | -1/3 | -1/3 ✅ |
| 1/3 * 2/3 | 2/9 | 2/9 ✅ |
| 1/3 / 2/3 | 1/2 | 1/2 ✅ |
| 1/0 | Исключение | Исключение ✅ |
